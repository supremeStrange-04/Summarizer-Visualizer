# ✨ Summarize & Visualize

> Upload. Summarize. Imagine.  
> A smart React app that transforms your text into a short summary and visual story.

---

## 🚀 Live Demo

🔗 [Check it out on Vercel/Netlify](glittering-vacherin-45f866.netlify.app)

---

## 📌 Features

✅ Upload or paste any text  
✅ Get a smart summary using AI  
✅ Auto-generate an image based on the summary  
✅ Regenerate the image by editing the summary  
✅ Clean, responsive UI with React + TailwindCSS  
✅ BONUS: Generate multiple images + loading spinners

---

## 🛠 Tech Stack

- **Frontend**: React (Vite or Create-React-App)
- **Styling**: TailwindCSS or plain CSS
- **APIs**:
  - 🔍 Text Summarization: Gemini API or Hugging Face summarization models
  - 🖼️ Image Generation: Hugging Face Stability AI model
- **HTTP**: Axios or Fetch for API requests

## ⚙️ How It Works

1. **Upload Text**: User uploads a `.txt` file or pastes text manually.
2. **Summarization**: Text is sent to a summarization API.
3. **Image Generation**: Summary is sent to an image generation API.
4. **Display**: App shows the summary and a generated image.
5. **Edit & Regenerate**: User can edit the summary and regenerate images.

- 🖼️ Generate 2–3 images instead of just one
